# 🚌 Mahesh Travels Website

A modern, responsive travel agency website developed using **HTML5, CSS3, and JavaScript**. This project showcases a professional online presence for **Mahesh Travels**, including bus rental services, fleet information, gallery, online booking, and contact details.

---

## 📌 Project Overview

Mahesh Travels is a responsive website designed to provide customers with an easy way to explore travel services, view available buses, book trips, and contact the company.

The website features a clean and modern user interface that works across desktop, tablet, and mobile devices.
